# 후앤모아 보안 적용 순서

> 순서를 지키면 사이트가 멈추지 않습니다. 상품·주문 데이터는 바뀌지 않습니다.
> 작업 전 백업: 2026-10-23 전체 테이블 백업 완료 (상품 1063 / 주문 10 / 주문상품 55 …)

## 무엇이 바뀌나요?

| 전 | 후 |
|---|---|
| 누구나 공개 키로 **모든 주문의 이름·전화·주소**를 볼 수 있음 | 손님은 **본인 연락처 + 주문번호(또는 이름)**가 맞는 주문만 조회 |
| 관리자 비밀번호가 공개 API·사이트 코드에 노출 | Supabase 로그인(이메일+비밀번호), 등록된 이메일만 관리자 |
| 매입원가(cost_price)가 손님에게도 전송됨 | 관리자 로그인 시에만 불러옴 |
| 누구나 상품 수정/삭제·이미지 업로드 가능 | 관리자만 가능 |
| 주문 금액을 브라우저가 계산해서 저장 (조작 가능) | 서버가 상품가 + 옵션 추가금(`JS(+3000원)`) + 배송비를 다시 계산 |

---

## 1단계 — 함수 만들기 (사이트 영향 없음)

1. Supabase 대시보드 → 후앤모아 프로젝트(`ksgjdhifezbdyilehxux`) 계정으로 로그인
2. 왼쪽 **SQL Editor** → New query
3. `01_functions.sql` 전체 붙여넣기 → **Run** → `Success` 확인

## 2단계 — 관리자 계정 만들기

1. **Authentication → Users → Add user → Create new user**
   - 이메일 / 비밀번호 입력, **Auto Confirm User** 체크 → Create
   - 관리자가 여러 명이면 각각 만들기
2. **Authentication → Sign In / Providers → Email** 에서 **"Allow new users to sign up" 끄기**
   (꼭 꺼주세요. 켜져 있으면 아무나 가입 시도는 가능합니다. 관리자 권한은 3번 목록에 있어야만 생깁니다)
3. SQL Editor에서 관리자 이메일 등록:
   ```sql
   insert into public.admin_users(email) values ('관리자이메일@example.com');
   ```

## 3단계 — 새 코드 배포

1. Replit에서 이 브랜치(`security/admin-auth-rls`) 코드를 받아 평소대로 빌드 → `firebase deploy`
2. 배포 후 확인 (이 시점에는 예전 방식도 아직 열려 있어서 문제가 생겨도 손님 주문은 계속 됩니다)
   - [ ] 상품 목록/상세가 보인다
   - [ ] 테스트 주문 1건 → 주문완료 화면에 주문번호·금액이 맞게 나온다 (옵션 추가금 상품도 1건)
   - [ ] 주문내역 조회 (연락처 + 주문번호 / 연락처 + 이름) 된다
   - [ ] 관리자 탭 → 이메일 로그인 → 주문 목록·매출/수익·상품 수정이 된다
   - [ ] 테스트 주문은 관리자에서 삭제

## 4단계 — 권한 잠그기 (배포하고 **1시간 이상 지난 뒤**)

> 사이트 첫 화면이 최대 1시간 캐시되므로, 바로 잠그면 예전 화면을 연 손님의 주문이 실패할 수 있습니다.

1. SQL Editor에 `02_lock_down.sql` 전체 붙여넣기 → **Run**
2. 맨 아래 결과에 나오는 storage 정책 목록을 확인
   (products 관리자 보기/업로드/수정/삭제 외에 "누구나 허용" 같은 정책이 남아 있으면 알려주세요)
3. 3단계 체크리스트를 한 번 더 확인 + 관리자에서 **사진 첨부 상품 등록** 1건 테스트

## 문제가 생기면

- `03_rollback.sql` 실행 → 권한이 보안 작업 이전 상태로 돌아갑니다 (데이터는 그대로)

## 나중에 (선택)

- 예전 관리자 비밀번호 값은 더 이상 쓰지 않습니다. 확인이 끝나면 지워도 됩니다:
  ```sql
  update public.store_settings set admin_password = null;
  ```
- 앞으로 `products`에 컬럼을 추가하면(예: 품절, 정가) `02_lock_down.sql`의 4)번 grant 목록과
  `App.tsx`의 `PUBLIC_PRODUCT_COLUMNS`에도 같이 추가해야 손님 화면에 보입니다.
