# 후앤모아 기능 업데이트 적용 순서

> SQL 파일은 번호 순서대로 한 번씩 실행합니다. 모두 "칸·함수 추가"만 하고 기존 데이터는 바꾸지 않으며, 다시 실행해도 안전합니다.
> - `01_batch1_settings.sql` — 사업자 정보·소식방 주소 ✅ 실행함
> - `02_home_layout.sql` — 홈 화면 배치(분류·브랜드·상품 순서) ✅ 실행함
> - `03_soldout_listprice.sql` — 품절 처리 · 정가 삭선 배율 · 품절 주문 막기 ✅ 실행함
> - `04_kakao_notify.sql` — 카카오톡 신규주문 알림 (관리자 나에게 보내기)

## 카카오톡 주문 알림 (feature/kakao-notify)

바뀌는 것
- 새 주문이 들어오면 30초~1분 안에 관리자 카카오톡 "나와의 채팅"으로 알림 (주문번호·주문자·금액·상품)
- 서버(Supabase pg_cron)가 보내므로 손님 주문 속도와 무관, 알림이 실패해도 주문은 그대로 접수 (실패분은 3번까지 다시 시도)
- 매일 새벽 토큰 자동 갱신 → 2달 만료 없이 연결 유지
- 관리자 > 설정 > **카카오톡 주문 알림**: REST API 키·Client Secret 저장/변경, 카카오 연결하기, 테스트 메시지, 알림 끄기/켜기, 다른 카카오 계정으로 바꾸기, 연결 끊기, 처음 설정 안내(도메인·Redirect URI 복사)
- 관리자 > 주문: 지난번 확인 이후 새 주문 빨간 배지 + NEW 표시, 화면을 켜두면 1분마다 자동 새로고침
- 카카오 키·토큰은 손님이 읽을 수 없는 테이블에 저장, 관리자 함수로만 변경

적용: SQL Editor 에 `04_kakao_notify.sql` 실행 → 결과에 `hm-kakao-keepalive`, `hm-kakao-notify` 2줄이 나오면 성공
→ 배포 후 관리자 > 설정 > 카카오톡 주문 알림의 "처음 설정 방법" 순서대로 카카오 앱 등록 → [카카오 연결하기]

## 품절 · 정가 삭선 (feature/soldout-listprice)

바뀌는 것
- 품절: 상품 관리 목록 [품절]/[판매 재개] 버튼, 상품 수정 화면 "판매 상태", 손님 화면 SOLD OUT 표시·담기 막힘·목록 맨 뒤로
- 사이즈·색상별 품절: 옵션에 `JL(품절)`처럼 적으면 그 버튼만 막힘
- 정가 삭선: 설정 > 가격 표시에서 배율(기본 30%) → ~~정가~~ **할인율%** 판매가. 상품별 정가 직접 지정 가능(비우면 자동, 0 = 표시 안 함)
- 서버(create_order)에서도 품절 상품·품절 옵션 주문 거절
- 설정 > 관리자 계정: 로그인한 상태에서 비밀번호 변경

적용: SQL Editor 에 `03_soldout_listprice.sql` 실행 → 결과에 `품절상품 0 · 정가배율 30` 이 나오면 성공

## 1차 업데이트 (feature/batch1-ui)

바뀌는 것
- 주문완료: "주문서 전송하기" 버튼 → 주문정보 복사 + 안내창 → [1:1 채팅방 열기]
- 주문완료 하단 "1:1 채팅" → "📢 신상 소식방" (단체 오픈채팅)
- 상품 썸네일: 사이즈 + 색상 표시, 상단 ⊞ 아이콘으로 2열/4열 전환 (4열은 사진+가격)
- 페이지 번호 1~10 표시, ‹ › 1페이지 / « » 10페이지 이동 (관리자 상품 목록도 동일)
- 뒤로가기: 휴대폰 뒤로가기·상단 < 버튼이 직전 화면으로, 홈은 보던 위치 그대로
- 맨 아래 사업자 정보 + 결제정보(설정의 무통장 입금 계좌) + 카카오톡 문의 버튼
- 관리자 로그인: 실패 원인 안내, 비밀번호 👁 보기 버튼
- 관리자 설정: 신상 소식방 주소, 사업자 정보 입력칸 추가

### 1. SQL 먼저 실행 (데이터 변경 없음, 칸만 추가)
Supabase → SQL Editor → `01_batch1_settings.sql` 전체 붙여넣기 → Run
→ 맨 아래 표에 사업자 정보가 나오면 성공

### 3. 테스트 주소에서 확인
- [ ] 상품 썸네일에 📏 사이즈 / 🎨 색상
- [ ] 상단 ⊞ 눌러 4열 ↔ 2열, 새로고침해도 고른 배열 유지
- [ ] 페이지 번호, ‹ › « » 이동
- [ ] 3페이지에서 상품 보고 뒤로가기 → 3페이지 같은 위치
- [ ] 맨 아래 사업자 정보·결제정보·카카오톡 문의
- [ ] 테스트 주문 → 주문서 전송하기 → 안내창 → 1:1 채팅방 열기 → 붙여넣기 내용 확인
- [ ] 신상 소식방 버튼이 단체 오픈채팅으로 열림
- [ ] 관리자 로그인 (👁 버튼), 설정 탭의 새 입력칸
- [ ] 테스트 주문 삭제
